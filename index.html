01 — About Hands-on detection work.

I spend my time on SIEM coverage that another engineer can review. Detections go into Splunk and Microsoft Sentinel, the logic lives in Sigma under version control, and tuning continues until an alert is worth acting on.

At LOG(N) Pacific that work covers brute-force, exfiltration, and early-ransomware behavior, plus canary tokens on critical assets and investigations that end in a runbook. The lab follows the same standard: every skill on this page has a write-up behind it.

Security Engineer · Cybersecurity Analyst / Detection & SecOps

Detection Engineering & SecOps

  • Built and maintained SIEM detection coverage in Splunk and Microsoft Sentinel for brute-force, exfiltration, and early-ransomware behavior across corporate and production systems.
  • Authored detections as code in Sigma, version-controlled in Git with test cases and tuning notes, and deployed through GitHub Actions so the logic stays reviewable and repeatable.

Vulnerability Management
